# FM Physio Dashboard

Demo dashboard for **Functional Movement Physio, Liverpool** — built for the agency review.

- Live site: https://openclaw903-coder.github.io/fm-physio-dashboard/
- Single static page (`index.html`) that reads live clinic data from Supabase.
- Pages: Overview, Enquiries, Cancellations, Tasks, Patients, AI Agents, Team & Packages, Physio Performance, Admin Today.
- Demo only — no live payments; the dashboard's AI assistant key is not configured by default.

Deploys: every push to `main` updates the GitHub Pages site.
